# Out-of-Distribution Graph Models Merging

* 会议/期刊：ICLR 2026
* 年份：2026
* 论文链接：[OpenReview](https://openreview.net/forum?id=93Y7jSUSpk) ｜ [arXiv](https://arxiv.org/abs/2506.03674)
* 代码链接：[OGMM](https://github.com/siriuslay/OGMM)

## 一句话总结

本文研究如何在无法访问源域数据和目标域数据的情况下，融合多个在不同域上预训练、甚至架构不同的 GNN；作者先从每个模型中反演生成合成图，再利用参数掩码和稀疏 MoE 动态融合专家，并在论文设置的 OOD 测试域上优于所选 baseline。

## 研究问题

### 背景

传统图域泛化通常需要同时访问多个源域的原始图数据，然后从头训练一个能够泛化到未知目标域的模型。

但现实中可能只保留了已经训练好的模型，而无法再次访问原始训练数据。例如：

* 不同机构分别训练了自己的 GNN，但由于隐私问题不能共享数据。
* 不同模型可能使用 GCN、GAT、GIN 等不同架构。
* 每个模型在自己的训练域上表现较好，但迁移到其他分布时性能明显下降。
* 重新收集全部数据并从头训练，会浪费已有模型中的知识。

论文将这一问题称为 **Out-of-Distribution Graph Models Merging，分布外图模型融合**。

输入是多个分别在不同源域上训练的预训练 GNN：

```math
\left\{
f(\Theta_1),
f(\Theta_2),
\ldots,
f(\Theta_M)
\right\}
```

其中，`\Theta_i` 表示第 `i` 个预训练模型的参数。

### 核心问题

如何在不访问源域数据和目标域数据的情况下，只利用多个预训练 GNN 中隐含的知识，得到一个能够泛化到未知目标域的融合模型？

论文定义的理想融合目标为：

```math
\Gamma^*
=
\arg\min_{\alpha}
E_{G_T,Y}
\left[
\ell
\left(
\Gamma
\left(
\alpha,
\left\{
\Theta_1,
\Theta_2,
\ldots,
\Theta_M
\right\}
\right),
G_T,
Y
\right)
\right]
```

其中：

* `G_T` 表示未知目标域。
* `\Gamma` 表示模型融合函数。
* `\alpha` 表示不同模型的融合权重。
* `\ell` 表示预测损失。

### 现有方法不足

* 传统图域泛化方法需要访问多个源域的原始图数据，通常还需要从头训练模型。
* 普通参数平均要求模型具有相同架构和相同参数维度，难以直接融合 GCN、GAT、GIN 等异构模型。
* 简单概率平均无法针对不同输入动态选择最合适的专家，也不能进一步调整专家中包含的域特定知识。

## 核心思路

1. 将每个预训练 GNN 当作一个冻结的监督模型，从随机节点特征和随机图结构出发，反演生成一批标签条件合成图。
2. 将所有专家生成的合成图合并，构造一个近似包含多个源域知识的训练集合。
3. 将每个预训练 GNN 保留为一个专家，通过参数 Mask 进行轻量调整，并使用稀疏 Top-`k` Gate 为每个输入动态选择专家。

论文首先假设目标域分布可以由多个源域分布混合得到：

```math
G_T
=
\sum_{i=1}^{M}
\alpha_i G_i
```

其中：

* `G_i` 表示第 `i` 个源域分布。
* `\alpha_i` 表示该源域对目标域的贡献。
* `M` 表示源域数量。

基于这一假设，融合模型也可以表示为多个源模型函数的组合：

```math
\Gamma
=
\sum_{i=1}^{M}
\alpha_i f(\Theta_i)
```

实际方法中，`\alpha_i` 并不是一组固定权重，而是由 MoE Gate 根据每个输入图动态产生。

## 方法要点

### 1. 标签条件图生成

* 做什么：

  从每个预训练 GNN 中反演出一批合成图，将隐藏在模型参数中的源域知识重新转化为可用于训练的数据。

* 输入输出：

  输入包括：

  * 冻结的预训练模型 `f(\Theta_i)`；
  * 从标准正态分布采样的节点特征 `X_i`；
  * 从标签空间随机采样的条件标签 `\hat y_i`。

  输出是第 `i` 个专家对应的合成图集合 `G_i^*`。每张合成图包含节点特征、邻接结构和条件标签。

* 为什么这样设计：

  融合阶段无法访问原始源域数据，但 Gate 和 Mask 仍然需要训练数据。

  因此，作者固定预训练模型，反过来优化模型输入，使生成图能够被该模型高置信度地预测为指定类别。

* 关键公式/机制：

  对任意两个节点 `j` 和 `k`，先拼接它们的节点特征，再通过三层 MLP 预测连边概率：

```math
A_{jk}^{i}
=
\sigma
\left(
\mathrm{MLP}_{\theta}
\left(
\left[
X_j^{i};
X_k^{i}
\right]
\right)
\right)
```

其中：

* `X_j^i` 和 `X_k^i` 是两个节点的特征。
* `[X_j^i;X_k^i]` 表示特征拼接。
* `A_{jk}^i` 表示节点之间的连边概率。
* `\sigma` 表示激活函数。

为了让连续的连边概率逐渐接近离散的 0 或 1，作者使用 Gumbel-Softmax：

```math
A_{jk}^{i}
=
\mathrm{softmax}
\left(
\frac{
\log A_{jk}^{i}
+
\mu
}{
\tau
}
\right)
```

Gumbel 噪声为：

```math
\mu
=
-\log
\left(
-\log e
\right),
\qquad
e
\sim
U(0,1)
```

其中，`\tau` 是温度参数。论文认为当 `\tau` 趋近于 0 时，生成的边会更加接近二值结果。

除了标签分类损失，作者还使用了 BN 统计匹配。按照论文的设计意图，可以简化理解为：

```math
R_{\mathrm{bn}}
=
\sum_L
\left\|
\mu_L(\hat X_i)
-
\mu_L^{\mathrm{BN}}
\right\|_2^2
+
\sum_L
\left\|
\sigma_L^2(\hat X_i)
-
\left(
\sigma_L^{\mathrm{BN}}
\right)^2
\right\|_2^2
```

其中：

* `\mu_L^{\mathrm{BN}}` 和 `(\sigma_L^{\mathrm{BN}})^2` 是预训练时保存在第 `L` 个 BN 层中的均值和方差。
* `\mu_L(\hat X_i)` 和 `\sigma_L^2(\hat X_i)` 是合成图经过该 BN 层时产生的统计量。

该正则要求合成图在模型中产生的隐藏表示，尽量接近模型训练时见过的数据分布。

作者还加入预测置信度正则，本质上是最小化预测熵：

```math
R_{\mathrm{conf}}
=
E_{G_i\sim G_j^*}
\left[
-
\sum_{c=1}^{C}
p_c(G_i)
\log p_c(G_i)
\right]
```

其中，`p_c(G_i)` 表示模型将图 `G_i` 预测为第 `c` 类的概率。

当预测接近 `[0.5,0.5]` 时，熵较大，说明类别模糊；当预测接近 `[0.99,0.01]` 时，熵较小，说明模型对类别更加确定。

最终生成损失为：

```math
L_{\mathrm{gen}}
=
\sum_{G_i\in G_j^*}
C
\left(
\hat y_i,
f(\Theta_j,G_i)
\right)
+
R_{\mathrm{bn}}
+
R_{\mathrm{conf}}
```

这三个部分分别要求：

1. 生成图能够被预测为指定类别。
2. 生成图的中间特征接近源模型保存的统计分布。
3. 源模型对生成图具有较高置信度。

* 我的理解：

  这一阶段不是恢复真实的源域图，而是在寻找“该模型认为比较典型”的输入图。

  因此，生成图反映的是预训练模型已经学到的知识和决策边界，而不是对原始数据的精确还原。如果预训练模型学到了错误相关性，生成器也可能将这种错误知识恢复出来。

### 2. 参数掩码专家

* 做什么：

  将每个预训练 GNN 保留为一个专家，不完整更新其全部参数，而是通过可学习的 Mask 对部分参数进行重新加权。

* 输入输出：

  输入是第 `i` 个专家的原始参数 `\theta_*^i` 和对应的 Mask `\omega^i`。

  输出是经过轻量调整的有效参数 `\hat\theta_*^i`。

* 为什么这样设计：

  如果完整微调每个专家，可能会破坏其原有源域知识，并带来较高的训练成本。

  如果完全冻结专家，又难以让专家适应其他源模型生成的数据。

  因此，作者通过 Mask 在“学习新域知识”和“保留原模型知识”之间进行平衡。

* 关键公式/机制：

```math
\hat\theta_*^i
=
\theta_*^i
\odot
\omega^i
```

其中，`\odot` 表示逐元素乘法。

对于某个 Mask 元素：

* 接近 1：基本保留原参数。
* 小于 1：减弱该参数的作用。
* 大于 1：增强该参数的作用。

论文主要将 Mask 加在分类头参数 `\theta_{\Phi}` 上，而冻结图编码器参数 `\theta_{\Psi}`。

作者认为分类头与具体任务和域相关决策边界联系更紧密，因此只调整分类头能够以较少的可训练参数完成适应。

* 我的理解：

  Mask 相当于给预训练参数安装了一组可调节旋钮。

  它没有重新学习一套完整参数，而是在已有参数的基础上决定哪些知识应该增强、哪些知识应该抑制。

  需要注意的是，这种方法并没有将多个模型真正压缩成一个普通 GNN，推理时仍然需要保留多个完整专家。

### 3. 稀疏 MoE 融合

* 做什么：

  根据当前输入图计算不同专家的匹配分数，只选择 Top-`k` 个专家参与预测，再对这些专家的输出进行加权融合。

* 输入输出：

  输入是当前图 `G_i` 和多个 Masked Expert。

  输出是不同专家的 Gate 权重以及最终融合预测。

* 为什么这样设计：

  不同专家来自不同源域，也可能采用不同架构，因此它们擅长的图模式不同。

  固定平均会让所有样本使用相同的融合方式，容易把无关专家的错误信息引入预测。

  动态 Gate 可以针对每个样本，选择更加匹配的专家。

* 关键公式/机制：

  标准 MoE 输出为：

```math
\hat H_i
=
\sigma
\left(
\sum_{j=1}^{M}
\mathrm{Gate}(G_i)_j
H_{i,j}
\right)
```

其中：

* `H_{i,j}` 是第 `j` 个专家对第 `i` 个样本的输出。
* `\mathrm{Gate}(G_i)_j` 是第 `j` 个专家的权重。
* `\hat H_i` 是融合后的输出。

Gate 首先计算当前样本对所有专家的匹配分数：

```math
Q(G_i)
=
G_iW_g
+
\epsilon
\cdot
\mathrm{softplus}
\left(
G_iW_n
\right)
```

高斯噪声满足：

```math
\epsilon
\sim
N(0,1)
```

其中：

* `W_g` 用于产生基础专家分数。
* `W_n` 用于控制噪声大小。
* 噪声用于增加训练初期的探索，避免所有样本过早集中到同一个专家。

随后，只保留得分最高的 Top-`k` 个专家：

```math
\mathrm{Gate}(G_i)
=
\mathrm{softmax}
\left(
\mathrm{TopK}
\left(
Q(G_i),
k
\right)
\right)
```

最终融合函数为：

```math
\Gamma_{\omega,W_g,W_n}(G_i)
=
\sum_{j=1}^{M}
\mathrm{Gate}(G_i)_j
f
\left(
\Theta_j,
\omega_j,
G_i
\right)
```

为了防止 Gate 始终只选择同一个专家，作者加入负载均衡正则：

```math
R_{\mathrm{gate}}
=
\mathrm{CV}
\left(
\sum_{G_i\in G^*}
\mathrm{Gate}(G_i)
\right)^2
```

其中，`\mathrm{CV}` 表示变异系数，可以理解为标准差与均值的比值。

如果所有样本都集中到同一个专家，不同专家收到的总权重差异会很大，`R_{\mathrm{gate}}` 也会增大。

论文中的 Mask 正则可以从功能上理解为：

```math
R_{\mathrm{mask}}
=
R_{\mathrm{adapt}}
+
R_{\mathrm{preserve}}
```

其中：

* `R_{\mathrm{adapt}}` 要求每个 Masked Expert 能够学习其他专家生成的知识。
* `R_{\mathrm{preserve}}` 限制 Mask 过度偏离 1，避免专家忘记原有知识。

最终模型融合损失为：

```math
L_{\mathrm{merge}}
=
\sum_{G_i\in G^*}
C
\left(
\hat y_i,
\Gamma_{\Phi}(G_i)
\right)
+
\lambda_{\mathrm{gate}}
R_{\mathrm{gate}}
+
\lambda_{\mathrm{mask}}
R_{\mathrm{mask}}
```

其中：

```math
\Phi
=
\left\{
\omega,
W_g,
W_n
\right\}
```

`\Phi` 是融合阶段需要训练的参数集合。

* 我的理解：

  Gate 解决“当前样本应该相信哪些专家”，Mask 解决“每个专家中的哪些参数需要调整”。

  整个模块可以概括为：

  * Gate：选择专家。
  * Top-`k`：减少无关专家干扰。
  * Mask：轻量调整专家。
  * Gate 正则：防止单一专家坍塌。
  * Mask 正则：防止原有知识被过度修改。

### 4. 训练与推理

* 训练：

  第一阶段进行标签条件图生成：

  1. 为每个预训练 GNN 初始化随机节点特征。
  2. 从标签空间中采样条件标签。
  3. 冻结预训练 GNN 参数。
  4. 使用边生成器预测邻接结构。
  5. 使用 `L_{\mathrm{gen}}` 更新节点特征和边生成器。
  6. 得到每个专家对应的合成图集合 `G_i^*`。
  7. 将所有专家生成的数据组合为 `G^*`。

  第二阶段进行模型融合：

  1. 保留所有预训练 GNN 作为专家。
  2. 初始化分类头 Mask、Gate 参数 `W_g` 和噪声参数 `W_n`。
  3. 使用合成图训练 Gate 和 Mask。
  4. 优化 `L_{\mathrm{merge}}`。
  5. 大部分原始 GNN 参数保持冻结。

* 推理：

  推理时不再运行图生成器。

  对一个真实目标图：

  1. Gate 计算它与所有专家的匹配分数。
  2. 选择 Top-`k` 个专家。
  3. 运行被选中的 Masked Expert。
  4. 对专家输出进行加权求和。
  5. 得到最终预测结果。

* 与已有方法的关键区别：

  * 与传统图域泛化不同：融合阶段不使用真实源域数据。
  * 与无源域适应不同：主方法训练融合器时也不使用目标域数据。
  * 与参数平均不同：不要求不同专家具有相同的参数结构。
  * 与普通集成不同：专家权重由每个输入样本动态决定。
  * 与真正的单模型参数融合不同：最终仍保留多个完整专家，本质上更接近动态 MoE 集成。

## 创新点

1. 提出了分布外图模型融合问题：在源域数据和目标域数据均不可访问的情况下，利用多个跨域预训练 GNN 构造具有 OOD 泛化能力的融合模型。
2. 提出了标签条件图反演方法，同时优化节点特征和图结构，将预训练模型中隐含的源域知识转化为少量合成图。
3. 使用 Masked Experts 和稀疏 Top-`k` Gate，在输出空间动态融合 GCN、GAT、GIN 等异构模型，不要求模型参数结构一致。

## 实验与结论

### 实验设置

* 数据集：

  主实验使用：

  * REDDIT-B
  * PTC
  * MUTAG
  * NCI1

  论文附录还报告了其他图分类和节点分类数据集上的补充实验。

* 任务：

  主实验为图分类。

  对每个主数据集，作者按照图的边密度划分不同域：

  * A 域：较低边密度。
  * B 域：中等边密度。
  * T 域：较高边密度，作为未知测试域。

  因此，论文主要验证的是同一数据集内部由结构统计差异产生的 OOD 偏移。

* baseline：

  单个预训练模型：

  * GCN-A、GAT-A、GIN-A
  * GCN-B、GAT-B、GIN-B

  简单集成：

  * Avg-PTM
  * Ens-Prob
  * Ens-HighConf

  参数融合：

  * Uni-Soup
  * Greedy-Soup

  生成式方法：

  * Inverse-X
  * Multi-GFKD

  其中，Inverse-X 和 Multi-GFKD 是作者为当前场景构造或扩展的比较方法。

* 指标：

  * Accuracy
  * Precision

  论文报告 10 次运行的均值和标准差。

### 主要结果

* OGMM 在论文列出的主实验方法中整体取得了最优结果。

* OGMM 在四个主数据集上的 Accuracy 为：

  * REDDIT-B：`76.98 ± 5.19`
  * PTC：`51.21 ± 3.74`
  * MUTAG：`45.62 ± 18.67`
  * NCI1：`66.84 ± 0.45`

* REDDIT-B 和 NCI1 上的提升相对明显，说明动态专家选择在较大数据集上具有较好的效果。

* PTC 上 OGMM 的 Accuracy 提升较小，说明该方法在所有数据集上并不都具有同样明显的优势。

* MUTAG 上 OGMM 的标准差达到 `18.67`，说明模型在小数据集上的稳定性仍然有限。

### 分析实验

* 消融：

  * 移除 MoE 后，模型改为简单融合专家输出，性能下降。
  * 移除 Mask 后，REDDIT-B 和 NCI1 上的性能明显下降。
  * 移除 `L_{\mathrm{gen}}`，直接使用随机输入训练融合模块，性能同样下降。
  * 在允许访问真实源域数据时，模型表现高于完全无源数据设置，说明合成图只能恢复部分源域知识，不能完全替代真实数据。

* 可视化：

  * t-SNE 结果显示，真实图与合成图在表示空间中存在一定重叠。
  * 生成图与真实图在节点数和边数范围上表现出一定相似性。
  * 训练阶段的 Gate 分布相对均衡。
  * 在真实目标域推理阶段，Gate 会明显偏向少数专家。

* 额外发现：

  * Top-`k` 中的 `k` 取 2 到 4 时通常效果较好。
  * 只对分类头增加 Mask，就能够获得具有竞争力的结果。
  * 分类头 Mask 平均只占两层 GNN 总参数量的约 20%。
  * 少量合成图就能取得较好性能，继续增加合成图数量不一定持续提升。
  * 增加源域数量不一定提升性能，因为每个域的数据量会减少，可能降低预训练专家质量。

## 不足与问题

1. **主实验 baseline 的覆盖范围和强度有限。**

   论文主要比较简单概率集成、Model Soup、Inverse-X 和 Multi-GFKD，缺少与更新的图模型融合、数据免费域泛化及多源无源适应方法进行充分比较。

   因此，实验能够说明 OGMM 优于论文所选择的方法，但不足以全面证明其相对于所有最新方法的优势。

2. **主实验中的跨域主要是同一数据集内部的人为划分。**

   A、B、T 都来自同一个原始数据集，只是按照边密度进行划分。

   这种设置确实产生了结构分布偏移，但没有验证跨数据集、跨数据来源、特征空间变化或语义机制变化下的泛化能力。

   因此，更准确的说法是：论文验证了同一数据集内部的结构 OOD，而不是更复杂的跨数据集泛化。

3. **混合分布假设较强，合成图质量依赖预训练模型。**

   论文假设目标域可以表示为源域的混合：

```math
G_T
=
\sum_{i=1}^{M}
\alpha_iG_i
```

   如果目标域包含所有源域都没有出现的新结构、新类别或新语义机制，已有专家的组合不一定能够覆盖目标域。

   此外，生成图只是能够让源模型高置信预测的图，不一定是真实、合法或具有实际语义的图。如果预训练专家存在偏差，生成器也可能恢复甚至放大这种偏差。

4. **部分公式和实验说明不够严谨。**

   * 公式（8）直接对单个标量连边概率使用 `softmax`，没有明确写出标准二分类 Gumbel-Softmax 所需的两个类别分数。若严格按照标量 Softmax 理解，输出会恒为 1，因此该公式的写法不完整。
   * 公式（9）中的 BN 统计期望记号较难理解，没有清楚地区分保存的 BN 统计量和随机变量。
   * 公式（19）的索引、阈值项及符号解释比较压缩，难以从正文中准确判断每一项如何约束 Mask。
   * 理论部分将 `G^*` 表述为带权混合分布，但实际算法中主要是将不同专家的生成数据组合到一个训练集合中，两者并不完全等价。
   * 部分 Mask 位置实验涉及在目标域上微调模型，与主方法完全不使用目标域数据的设置不同，只能作为参数位置分析，不能直接视为主设定下的性能证据。

5. **最终并没有真正合并成一个普通的单模型。**

   OGMM 推理时仍然需要保存：

   * 多个完整 GNN 专家；
   * 每个专家对应的 Mask；
   * Gate 网络。

   因此，它更接近动态专家集成，而不是将多个模型压缩成一个参数统一的 GNN。

   随着专家数量增加，存储开销和推理成本也会增加。

## 和我当前研究的关系

* 可借鉴点：

  对当前 Route A 最有价值的不是合成图生成，而是：

  1. 使用 Query 条件的 Top-`k` Gate，动态选择对当前 Query 域最有帮助的源域更新。
  2. 使用模块级 Mask，选择每个源域更新中哪些层或模块值得迁移。

  你当前的 Route A 是：

  * Support 域分别进行本地训练。
  * 获得各域的参数更新。
  * 根据更新方向和域统计构建语义域图。
  * 域 GNN 输出聚合权重。
  * 聚合本地更新得到新的全局模型。
  * 使用 Query 域损失训练聚合器。

  可以将域 GNN 输出作为全局先验 `\pi_d`，再结合 Query 表示产生最终域权重：

```math
s_d
=
\log\pi_d
+
g(c_Q,z_d)
```

```math
w
=
\mathrm{softmax}
\left(
\mathrm{TopK}
\left(
s,
K
\right)
\right)
```

  其中：

  * `z_d` 是第 `d` 个源域的表示。
  * `c_Q` 是当前 Query 批次的表示。
  * `w_d` 是最终参与聚合的域权重。

* 可复用模块：

  1. **Top-`k` 域更新选择**

```math
\Delta\theta
=
\sum_{d\in\mathrm{TopK}}
w_d
\Delta\theta_d
```

  只聚合与当前 Query 最相关的少数域更新，减少无关源域造成的负迁移。

  2. **模块级 Mask**

```math
\Delta\theta^{(l)}
=
\sum_d
w_d
m_d^{(l)}
\Delta\theta_d^{(l)}
```

  其中，`m_d^{(l)}` 表示第 `d` 个域在第 `l` 个模块上的可迁移程度。

  可以分别控制：

  * 节点与边编码器；
  * 局部消息传递层；
  * 全局 Attention 层；
  * 消息原型；
  * 分类头。

  3. **与消息原型结合**

  假设每层存在 `K` 个全局共享的消息原型：

```math
P^{(l)}
=
\left\{
p_1^{(l)},
p_2^{(l)},
\ldots,
p_K^{(l)}
\right\}
```

  每条消息可以由这些公共原型动态加权构成：

```math
m_{\mathrm{proto}}^{(l)}
=
\sum_{k=1}^{K}
a_k^{(l)}
p_k^{(l)}
```

  或者用原型组合增强原始消息：

```math
\tilde m^{(l)}
=
m^{(l)}
+
\beta_l
\sum_{k=1}^{K}
a_k^{(l)}
p_k^{(l)}
```

  可以分别统计第 `d` 个源域和 Query 域对不同消息原型的使用分布 `r_d` 与 `r_Q`。

  在域选择分数中加入原型分布相似度：

```math
s_d
=
\log\pi_d
+
g(c_Q,z_d)
+
\eta
\mathrm{sim}
\left(
r_Q,
r_d
\right)
```

  这样可以优先选择与 Query 具有相似消息传递模式的源域，实现：

  * 选择哪个源域；
  * 选择哪些消息原型；
  * 选择聚合模型的哪些模块。

* 能否作为 baseline：

  不能直接把论文报告的 OGMM 结果作为 Route A 的完全公平 baseline，因为两者的数据访问条件和最终模型形式不同：

  * OGMM 在融合阶段不能访问源域数据和目标域数据。
  * Route A 在元训练阶段能够访问 Support 域和 Query 域。
  * OGMM 推理时保留多个专家。
  * Route A 的目标是聚合本地更新，得到一个统一的全局模型。

  更合理的方式是：

  * 将 OGMM 作为相关工作和方法启发。
  * 在统一的数据划分和数据访问条件下，实现一个 OGMM-style MoE 对照版本。
  * 或将其作为“保留多个域专家并进行动态路由”的对照方法。

* 对我最有启发的一点：

  域图不一定需要直接给出最终聚合权重。

  更合理的设计是：

  1. 域图学习源域之间的全局关系和可靠性先验。
  2. Query 表示动态修正不同源域的权重。
  3. 消息原型分布衡量源域和 Query 在消息传递模式上的相似性。
  4. 模块级 Mask 决定每个源域更新中的哪些部分值得迁移。

  最终可以形成：

```math
\mathrm{DomainPrior}
+
\mathrm{QueryRouting}
+
\mathrm{PrototypeMatching}
+
\mathrm{ModuleMask}
```

  即“选域、选消息、选模块”的细粒度聚合。

## 最终总结

* 值不值得重点跟进：

  值得重点跟进其稀疏 Gate、Masked Expert 和异构模型输出融合思想，但不建议直接将完整的模型反演生成模块搬到 Route A 中。

  Route A 已经能够访问真实 Support 域数据，重新生成合成图会额外增加计算成本和生成误差。

  更适合复用的是动态域选择、Top-`k` 稀疏聚合和模块级更新筛选机制。

* 一句话评价：

  这是一篇问题设定新颖、异构模型融合思路清晰的工作，但主要实验仍局限于同一数据集内部构造的域偏移，baseline 强度、部分公式严谨性以及“真正融合为单模型”的程度仍有不足。
