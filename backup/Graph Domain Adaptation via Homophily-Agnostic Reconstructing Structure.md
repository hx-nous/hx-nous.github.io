# Graph Domain Adaptation via Homophily-Agnostic Reconstructing Structure

- 会议/期刊：AAAI 2026，Proceedings of the AAAI Conference on Artificial Intelligence
- 年份：2026
- 论文链接：https://arxiv.org/abs/2602.07573
- 代码链接：无
## 一句话总结

这篇论文解决无监督图领域自适应中目标图无标签、无法提前判断其同配或异配程度的问题，提出 RSGDA 方法，通过分别重构源图和目标图的同配图与异配图，再分别滤波、编码、重构和对齐，在多种同配与异配图迁移任务上取得较好效果，尤其强调了在异配图场景下的优势。

## 研究问题

### 背景

图领域自适应，Graph Domain Adaptation，简称 GDA，关注的是：源图有标签，目标图没有标签，如何把源图中学到的分类知识迁移到目标图上。

在图学习中，很多传统 GNN 默认图具有同配性，也就是相似节点更容易相连。例如同领域论文互相引用、兴趣相似的人互相关注。但真实图中也常见异配性，也就是相连节点可能属于不同类别，例如老师和学生、买家和卖家、不同功能的蛋白质节点等。

### 核心问题

目标图没有标签，因此无法提前计算目标图的同配率，也就无法判断目标图到底更偏同配还是更偏异配。现有 GDA 方法如果默认图是同配的，在异配图或同配程度变化较大的跨图迁移场景中容易失效。

### 现有方法不足

- 许多 GDA 方法默认源图和目标图都具有同配性，依赖“邻居节点相似”这一假设，在异配图上性能下降。
- 一些异配图学习方法需要标签来判断或调整结构，不适合目标图无标签的无监督 GDA 场景。
- 现有方法往往把同配信息和异配信息混在一个表示空间中学习与对齐，容易造成结构信号混淆。
- 真实图通常不是纯同配或纯异配，而是不同节点、不同局部区域具有不同程度的同配性，简单地把整张图判定为同配图或异配图比较粗糙。

## 核心思路

1. 不提前判断目标图是同配还是异配，而是对源图和目标图都分别重构出同配图和异配图两个版本。
2. 对同配图使用偏低通的滤波方式提取相似节点之间的平滑信息；对异配图使用偏高通的滤波方式提取节点之间的差异信息。
3. 使用两个编码器分别学习同配表示和异配表示，再将源域和目标域的同配表示、异配表示分别对齐，从而减少源目标之间的结构分布差异。

## 方法要点

### 1. 模块 A：结构重构，Structure Reconstruction

- 做什么：

  将原始源图和目标图分别重构成两个版本：

  - 同配图：更强调相似节点之间的连接。
  - 异配图：更强调不相似节点之间的关系。

- 输入输出：

  输入：

  - 原始邻接矩阵 `A^S, A^T`
  - 原始节点特征 `X^S, X^T`

  输出：

  - 源域同配图 `A_O^S`
  - 源域异配图 `A_E^S`
  - 目标域同配图 `A_O^T`
  - 目标域异配图 `A_E^T`

- 为什么这样设计：

  目标域没有标签，不能提前判断目标图的同配程度。如果只用一种图结构，模型可能只适合同配图或只适合异配图。通过同时构造同配图和异配图，模型可以同时保留“相似关系”和“差异关系”。

- 关键公式/机制：

  同配图构造的核心思想是：如果两个节点特征距离小，就应该更容易连接。

  节点 `i` 和节点 `j` 的特征距离定义为：

  
```math
F_{ij}=\|x_i-x_j\|^2
```


  其中，`x_i` 和 `x_j` 分别表示节点 `i` 和节点 `j` 的特征向量。若 `F_{ij}` 越小，说明两个节点越相似，因此它们在同配图中越应该被连接。

  同配图优化目标可以理解为：

  
```math
\min_{\hat{A}_{ij}}
  \hat{A}_{ij}F_{ij}
  +
  \hat{A}_{ij}^{2}
  +
  \left(\hat{A}_{ij}^{(l)}-\hat{A}_{ij}\right)^2
```


  其中：

  - `\hat{A}_{ij}F_{ij}`：鼓励特征相似的节点连接。如果两个节点特征距离 `F_{ij}` 较小，那么给它们较大的连接权重代价较低。
  - `\hat{A}_{ij}^{2}`：防止边权重过大，避免重构出的图结构过于极端。
  - `\left(\hat{A}_{ij}^{(l)}-\hat{A}_{ij}\right)^2`：引入多跳邻居信息，不只依赖一跳邻居关系。

  该优化目标还受到如下约束：

  
```math
\hat{A}_{ij}>0
```


  
```math
\sum_{j=1}^{N}\hat{A}_{ij}=1
```


  第一个约束表示重构后的边权重应为正数；第二个约束表示节点 `i` 与其他节点的连接权重之和为 1，可以理解为对每个节点的连接分布进行归一化。

  异配图构造使用互补相似矩阵和互补邻接矩阵。

  首先，节点特征相似度矩阵为 `S`，则节点之间的不相似程度可以表示为：

  
```math
\bar{S}=1-S
```


  原始邻接矩阵为 `A`，则原来不相连的节点关系可以表示为：

  
```math
\bar{A}=1-A
```


  然后通过逐元素相乘得到异配候选图：

  
```math
\tilde{H}=\bar{S}\odot\bar{A}
```


  其中，`\odot` 表示 Hadamard product，即逐元素相乘。

  这个公式的含义是：如果两个节点在特征上不相似，同时在原始图结构中也不相邻，那么它们可以作为异配关系的候选节点对。

  为了避免异配图过于稠密，论文只保留每个节点对应的前 `k` 条最重要的异配边，文中实验里保留的是前 5 条边。

- 我的理解：

  结构重构是本文最核心的第一步。它不是直接相信原始图的边，而是重新构造两种视角：一种找“像我的人”，另一种找“不像我的人”。这样模型不用提前知道目标图到底是同配还是异配，而是把两种可能都保留下来。

### 2. 模块 B：自适应图滤波与双编码器表示学习

- 做什么：

  对重构出的同配图和异配图分别提取信号，然后用两个编码器分别学习同配表示和异配表示。

- 输入输出：

  输入：

  - 同配图 `A_O`
  - 异配图 `A_E`
  - 节点特征 `X`

  输出：

  - 同配表示 `Z_O`
  - 异配表示 `Z_E`

- 为什么这样设计：

  同配图和异配图包含的信息不同：

  - 同配图中，相连节点更可能相似，适合平滑。
  - 异配图中，相连节点可能不同，适合保留差异。

  因此不能用同一种滤波和同一个编码器混合处理，否则同配信息和异配信息可能互相干扰。

- 关键公式/机制：

  异配信号：

  
```math
Z_E=\gamma\left(\frac{1}{2}L_E\right)^kX
```


  同配信号：

  
```math
Z_O=(1-\gamma)\left(I-\frac{1}{2}L_O\right)^kX
```


  其中：

  - `L_E`：异配图拉普拉斯矩阵。
  - `L_O`：同配图拉普拉斯矩阵。
  - `k`：滤波阶数。
  - `\gamma`：可学习参数，用于平衡异配信息和同配信息。

  同配分支近似低通滤波，强调邻居之间的共性；异配分支近似高通滤波，强调节点与邻居之间的差异。

  编码器公式：

  
```math
Z_E = E_{\theta_E}(Z_E)
```


  
```math
Z_O = E_{\theta_O}(Z_O)
```


  这个公式中左右两边都写 `Z_E, Z_O`，容易混淆。更清楚的理解是：

  
```math
\hat{Z}_E = E_{\theta_E}(Z_E)
```


  
```math
\hat{Z}_O = E_{\theta_O}(Z_O)
```


  即：

  - 异配滤波信号进入异配编码器，得到异配表示。
  - 同配滤波信号进入同配编码器，得到同配表示。

  两个编码器都是 MLP，且不共享参数。

- 我的理解：

  这一部分像是给图配了两个专家：同配专家负责找相似性，异配专家负责找差异性。参数 `\gamma` 则负责决定当前任务中更应该相信哪一种信号。这个设计比直接用一个 GNN 聚合原始邻居更稳健，因为它避免了在异配图中盲目平滑导致类别信息混淆。

### 3. 模块 C：同配/异配分别对齐与特征重构

- 做什么：

  一方面通过解码器保证学到的表示没有丢掉原始信息，另一方面通过 KL 散度让源域和目标域在同配空间、异配空间中分别对齐。

- 输入输出：

  输入：

  - 源域同配表示 `Z_O^S`
  - 源域异配表示 `Z_E^S`
  - 目标域同配表示 `Z_O^T`
  - 目标域异配表示 `Z_E^T`

  输出：

  - 对齐后的源目标表示
  - 用于目标节点分类的最终目标域表示

- 为什么这样设计：

  解码器重构只能保证源域和目标域各自学到的表示保留了节点信息，但不能保证源域和目标域处于同一个可迁移的表示空间。因此还需要对齐损失。

  同时，直接整体对齐可能把同配信号和异配信号混在一起，所以本文采用分别对齐：

  - 源域同配表示对齐目标域同配表示。
  - 源域异配表示对齐目标域异配表示。

- 关键公式/机制：

  对齐损失：

  
```math
\mathcal{L}_A
  =
  KL(Z_E^S\|Z_E^T)
  +
  KL(Z_O^S\|Z_O^T)
```


  其中：

  - `KL(Z_E^S\|Z_E^T)`：缩小源域异配表示和目标域异配表示的分布差异。
  - `KL(Z_O^S\|Z_O^T)`：缩小源域同配表示和目标域同配表示的分布差异。

  特征重构损失：

  
```math
\mathcal{L}_{RE}
  =
  \sum_{i=1}^{N}
  \left(
  1-
  \frac{
  Z_i^\top \bar{Z}_i
  }{
  \|Z_i\|\cdot\|\bar{Z}_i\|
  }
  \right)^\beta
```


  它使用缩放余弦误差，比较编码后的表示 `Z_i` 与解码器重构出的表示 `\bar{Z}_i` 是否相似。

  相关性降低损失：

  
```math
\mathcal{L}_{CR}
  =
  \frac{1}{d^2}
  \sum_{i=1}^{d}
  (K_{ii}-1)^2
  +
  \frac{1}{d^2-d}
  \sum_{i=1}^{d}
  \sum_{j\neq i}
  K_{ij}^2
```


  其中：

  
```math
K_{ij}
  =
  \frac{
  Z_{Ei}^{\top}Z_{Oj}
  }{
  \|Z_{Ei}\|\cdot\|Z_{Oj}\|
  }
```


  该损失用于防止表示塌缩，即避免所有节点都被编码成相似的向量，同时减少不同表示维度之间的冗余。

  总损失：

  
```math
\mathcal{L}
  =
  \mathcal{L}_{CR}
  +
  \mu_1\mathcal{L}_{RE}
  +
  \mu_2\mathcal{L}_A
```


  其中：

  - `\mathcal{L}_{CR}`：防止表示塌缩。
  - `\mathcal{L}_{RE}`：保证表示能保留原始信息。
  - `\mathcal{L}_A`：进行源目标对齐。
  - `\mu_1, \mu_2`：控制重构损失和对齐损失的权重。

- 我的理解：

  重构和对齐不是重复功能。重构保证“每个域自己没有丢信息”，对齐保证“源域和目标域可以迁移”。如果只有重构，源域和目标域可能各自学得很好，但不在同一个空间中；如果只有对齐，模型可能为了让源域和目标域接近而丢掉有用信息。因此两者需要同时使用。

### 4. 训练与推理

- 训练：

  训练时源图和目标图同时进入模型。流程如下：

  1. 对源图和目标图分别重构同配图和异配图。
  2. 对同配图进行低通滤波，对异配图进行高通滤波。
  3. 使用两个 MLP 编码器分别学习同配表示和异配表示。
  4. 在每个域内部拼接同配表示和异配表示。
  5. 使用解码器做特征重构，计算 `\mathcal{L}_{RE}`。
  6. 使用相关性降低损失防止表示塌缩，计算 `\mathcal{L}_{CR}`。
  7. 分别对齐源域和目标域的同配表示、异配表示，计算 `\mathcal{L}_A`。
  8. 使用总损失联合训练整个表示学习框架。

  需要注意的是，论文公式中的总损失主要写了 `\mathcal{L}_{CR}, \mathcal{L}_{RE}, \mathcal{L}_A`，源域分类监督项没有在该公式中清晰展开。但由于任务是源域有标签的节点分类，实际分类预测通常还需要使用源域标签训练分类器或分类头。

- 推理：

  推理时只需要目标图：

  1. 对目标图重构同配图和异配图。
  2. 分别滤波得到目标同配信号和异配信号。
  3. 使用编码器得到 `Z_O^T` 和 `Z_E^T`。
  4. 拼接得到目标域最终表示：

     
```math
Z^T = concat(Z_O^T, Z_E^T)
```


  5. 将目标域最终表示送入分类器，得到目标节点预测结果。

- 与已有方法的关键区别：

  传统 GDA 方法通常直接使用原始图结构，并默认邻居之间相似；RSGDA 不直接依赖原始图，而是先重构同配图和异配图，再分别提取和对齐两类信号。它也不是典型的消息传递 GNN，而是使用图滤波加 MLP 编码器/解码器的方式利用图结构。

## 创新点

1. 提出 homophily-agnostic 的 GDA 框架，不需要提前知道目标图是同配还是异配。
2. 对源图和目标图分别重构同配图和异配图，使模型能够同时利用相似结构和差异结构。
3. 设计同配/异配分别滤波、分别编码、分别对齐的机制，避免两类结构信号混淆。
4. 引入特征重构和相关性降低损失，缓解表示丢失与表示塌缩问题。

## 实验与结论

### 实验设置

- 数据集：

  论文使用了多类图数据集，包括：

  - Airport：USA, Brazil, Europe
  - Citation：ACMv9, Citationv1, DBLPv7
  - Social：Blog1, Blog2
  - WebKB：Texas, Cornell, Wisconsin
  - ACM 同配变化数据：ACM3, ACM4

- 任务：

  跨网络节点分类，即从一个有标签源图迁移到一个无标签目标图。

- baseline：

  包括：

  - GCN
  - DANN
  - DANE
  - UDAGCN
  - ASN
  - EGI
  - GRADE-N
  - JHGDA
  - SpecReg
  - PA
  - HGDA

- 指标：

  节点分类准确率，Accuracy。

### 主要结果

- RSGDA 在 Airport、Citation、ACM、Blog、WebKB 等多个跨图迁移任务中整体表现较强。
- 在同配程度差异较大的任务中，例如 ACM3 到 ACM4、ACM4 到 ACM3，RSGDA 仍然取得较好效果，说明其同配无关设计具有一定稳健性。
- 在 WebKB 这类典型异配图任务上，RSGDA 在多个迁移方向上相比多数 baseline 有明显提升，说明同配/异配分别建模对异配图迁移有帮助。
- 需要注意的是，论文正文声称 RSGDA 在所有跨域场景中表现最好，但表 3 中 CO→WI 这一列 SpecReg 明显高于 RSGDA，正文表述与表格存在不一致，阅读时需要留意。

### 分析实验

- 消融：

  论文比较了 RSGDA 与三个变体：

  - RSGDA_1：去掉相关性降低损失 `\mathcal{L}_{CR}`。
  - RSGDA_2：去掉特征重构损失 `\mathcal{L}_{RE}`。
  - RSGDA_3：不使用结构重构，而是随机分图。

  结果显示完整 RSGDA 通常最好，尤其 RSGDA_3 下降较明显，说明结构重构模块是关键贡献。

- 可视化：

  图 2(b) 展示了原始图、重构同配图、重构异配图的同配分布变化，说明 RSGDA 的结构重构可以一定程度上分离同配和异配结构。

- 额外发现：

  图 3 显示不同 hop 下同配率会变化，说明只看一跳邻居是不够的，多跳结构信息对重构同配图有帮助。图 5 表明 `\mu_1` 和 `\mu_2` 在一定范围内变化时，RSGDA 的性能相对稳定。

## 不足与问题

1. 源域分类监督损失在论文总目标公式中没有清晰展开，训练分类器的具体细节需要进一步查看代码或补充材料。
2. 异配图构造依赖“特征不相似且原来不相邻”的假设，但这个假设不一定总是成立。
3. 方法包含结构重构、滤波、双编码器、解码器、相关性损失和 KL 对齐等多个部分，整体流程较复杂，复现成本可能较高。
4. 论文正文与表格结果存在至少一处不一致，例如 CO→WI 任务中 RSGDA 并不是最好。
5. 官方代码链接暂未找到，可能会影响复现和进一步验证。
6. 虽然方法声称 homophily-agnostic，但重构图的质量仍然依赖节点特征相似度和结构假设；如果节点特征本身质量较差，方法效果可能受影响。

## 和我当前研究的关系

- 可借鉴点：

  如果当前研究涉及图领域自适应、异配图学习、跨图迁移、无监督目标域适配，那么这篇论文的“同配/异配分解建模”非常值得借鉴。它提供了一种不依赖目标标签判断同配程度的处理思路。

- 可复用模块：

  - 同配图结构重构模块。
  - 异配图结构重构模块。
  - 低通/高通双滤波模块。
  - 同配/异配双编码器结构。
  - 同配/异配分别对齐损失。
  - 特征重构损失与相关性降低损失。

- 能否作为 baseline：

  可以作为图领域自适应，尤其是异配图 GDA 或同配程度变化场景下的重要 baseline。但由于官方代码暂未找到，复现时可能需要自行实现结构重构与训练流程。

- 对我最有启发的一点：

  不要把一张图粗暴地判断为同配或异配。现实图往往同时存在同配和异配结构，因此可以把图拆成多个结构视角，再分别学习和对齐。这种“结构分解 + 分支对齐”的思想可以推广到其他图迁移或图表示学习任务中。

  值得跟进，尤其适合关注图领域自适应、异配图学习、图结构重构和无监督迁移学习的研究方向。

- 一句话评价：

  RSGDA 的核心价值在于把“目标图同配程度未知”这个难题转化为“同时构造同配视角和异配视角并分别对齐”的问题，是一篇思路清晰、模块较完整、对异配图迁移有启发意义的 GDA 工作。
